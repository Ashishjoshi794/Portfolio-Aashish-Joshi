## ✨ Features

- **Hero Section**: 3D interactive particle scene and dynamic typography
- **About & Education**: Academic background, journey timeline, and core metrics
- **Skills Matrix**: Categorized technical skills with interactive proficiency indicators
- **Projects Showcase**: Detailed project cards with live demo links, source code, and modal deep-dives
- **Certificates**: Verified credentials and course completions
- **AI Chatbot**: Built-in assistant to answer questions about skills, background, and projects
- **Dark Mode & Responsive**: Seamless experience across mobile, tablet, and desktop

- **3D Graphics**: [Three.js](https://threejs.org/) / Canvas

## 🚀 Getting Started

### Prerequisites
- [Node.js](https://nodejs.org/) (version 18 or higher)
- npm or yarn

### Installation

1. **Clone the repository:**
   ```bash
   git clone https://github.com/Ashishjoshi794/Portfolio-Aashish-Joshi.git
   cd Portfolio-Aashish-Joshi
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Start development server:**
   ```bash
   npm run dev
   ```

4. **Build for production:**
   ```bash
   npm run build
   ```
